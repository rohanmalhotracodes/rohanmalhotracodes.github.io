03 · Selected project

OmniSprint turns scattered engineering signals into a single view of delivery risk.

OS
OmniSprint · May 2026

AI sprint-risk intelligence for engineering teams

Python · FastAPI · React · TypeScript
Roadmaps, issues, pull requests and CI results often describe the same project from different angles. OmniSprint combines those sources so teams can see blockers, deadline risk and likely regression causes without manually reconciling every system.

Engineering data was fragmented across roadmaps, GitHub issues, pull requests and CI pipelines, making delivery risk difficult to identify early.

Built SQL-based cross-source retrieval, risk scoring, regression-cause detection and Gemini-powered follow-ups with evidence-backed explanations.
